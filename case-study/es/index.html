El problema

El fraude con tarjetas es un problema de predicción adversarial y extremadamente desbalanceado (~1% de transacciones). Un modelo que predice "legítima" para todo consigue 99% de accuracy y cero fraudes detectados — por eso este proyecto trata explicabilidad y calibración como requisitos de primera clase, no como añadidos posteriores.

La respuesta es un híbrido: reglas para transparencia, gradient boosting para descubrir patrones, grafos y embeddings para señales a nivel de red, e infraestructura que mantiene todo honesto con el tiempo.
