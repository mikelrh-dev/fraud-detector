## 2. Rules

- Every fix proves itself by going red first. A fix with no failing-before reproduction
  is not done.
- No `git add .`. The user's `README.md` / `README.es.md` are not ours.
- No `git checkout -- <path>` to revert — it has destroyed uncommitted work three times
  in this repo. Use explicit edits.
- Baselines that must hold: backend `1018 passed, 30 skipped, 8 xfailed` · ruff clean ·
  mypy clean 69 files · frontend `745 vitest pass` · build clean · CSS `67,706` bytes
  (`56bc2179d41d0990`), plus whatever D6-1 legitimately changes and is measured.
